Lecteur RFID
connecté

Un microcontrôleur ESP8266 qui lit des badges RFID et publie leur identifiant en temps réel, par MQTT, vers un broker hébergé sur un Raspberry Pi. Un petit objet connecté complet — du capteur au message réseau — réalisé en cours de Systèmes Embarqués.

Le principe

Le module RFID (MFRC522) dialogue avec l'ESP8266 par le bus SPI. Dès qu'un badge est détecté, le microcontrôleur lit son identifiant unique (UID), se connecte au WiFi puis au broker MQTT, et publie l'UID sur un topic dédié. Toute la gestion de connexion est asynchrone et se rétablit toute seule en cas de coupure.

ESP8266 MFRC522 SPI MQTT WiFi 
// Badge détecté → lecture de l'UID
if (mfrc522.PICC_IsNewCardPresent() &&
    mfrc522.PICC_ReadCardSerial()) {

  String uid = "";
  for (byte i = 0; i < mfrc522.uid.size; i++)
    uid += String(mfrc522.uid.uidByte[i], HEX);
  uid.toUpperCase();

  // Publication temps réel vers la Pi
  if (mqttClient.connected())
    mqttClient.publish("esp/rfid/uid",
                        1, false, uid.c_str());
}

Le code

Écrit en C++ sous Arduino, le firmware s'appuie sur des callbacks d'événements WiFi et MQTT pour rester réactif sans bloquer la boucle principale. À chaque badge lu, l'UID est formaté en hexadécimal puis envoyé au broker — prêt à être consommé par n'importe quel abonné (journalisation, contrôle d'accès, supervision).
